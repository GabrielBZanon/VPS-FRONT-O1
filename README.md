# README - Sistema IPlast

## Sobre
Sistema para gerenciar:
- Produtos (estoque)
- Funcionários
- Clientes

## Telas Principais

1. **Página Inicial**
   - Cards para acessar cada seção
   - Menu de navegação

2. **Cadastros**
   - Formulários para adicionar novos itens
   - Lista com opções de editar/excluir

## Como Usar
1. Baixe os arquivos
2. Abra `index.html` no navegador
3. Use os botões para navegar
